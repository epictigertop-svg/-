# BEATCUT — 숏폼 자동 편집기

릴스·틱톡·쇼츠 스타일(9:16) 영상을 브라우저에서 자동으로 편집합니다. 서버가 필요 없고, 파일은 업로드되지 않습니다.

## 영상 유형
- **인물 편집**: 아이돌·셀럽 사진 여러 장과 짧은 클립을 비트마다 전환하고 효과·음악·효과음을 입힙니다. 사진을 누르면 얼굴 위치(초점)를 지정할 수 있어요.
- **하이라이트 편집**: 게임·운동 영상에서 사용자가 고른 구간에 슬로우모션, 임팩트 플래시, 흔들림, 리플레이 같은 효과를 넣습니다.

## 구성
- `js/music.js` — 장르별 음악 합성(K-POP, 펑크, 발라드, 폰크, EDM, 힙합, 로파이, 펑크 록), 효과음, BPM 분석
- `js/effects.js` — 장면 전환 17종, 화면 효과 23종, 장르별 추천표
- `js/engine.js` — 타임라인, 캔버스 렌더러, 영상 동기화, 재생, 녹화(MediaRecorder)
- `js/app.js` — 화면/입력 처리

## 실행
정적 파일이라 아무 웹서버로 열면 됩니다. 예: `python3 -m http.server --directory studio`
GitHub Pages에서는 `https://<계정>.github.io/<저장소>/studio/` 경로로 열립니다.
